# Únete a nosotros

¡Bienvenido a Artemis ! Nos alegra que quieras unirte a esta épica aventura. Esta página te guiará paso a paso para crear tu cuenta, instalar el juego y unirte a nuestra comunidad.

### 🌐 Sitio web oficial

👉 [ Acceda al sitio web de Artemis](https://artemis.mservers.ovh/)

Desde el sitio web, usted podrá:

* Crea tu cuenta
* Descarga el juego
* Vota y Gana Ogrinas

### 🧑‍💻 Creación de cuenta

* **Registro** : Si aún no tienes una cuenta, visita el sitio web y sigue los pasos de registro (rápidos e intuitivos).

<figure><img src="../.gitbook/assets/image_1.png" alt=""><figcaption></figcaption></figure>

* **Iniciar sesión** : Si ya estás registrado, inicia sesión para sumergirte directamente en el mundo de Artemis.

<figure><img src="../.gitbook/assets/image_2.png" alt=""><figcaption></figcaption></figure>

### 💾 Descarga e instala el juego

1. Dirígete a la sección **de Descargas** del sitio web.

* 📥 Elige el enlace **de MEDIAFIRE** o **Google Drive** (son idénticos).
* Obtendrás un archivo comprimido.

<figure><img src="../.gitbook/assets/image_3.png" alt=""><figcaption></figcaption></figure>

2. **Inicia el lanzador** :

* Abrir el archivo `Uplauncher.exe`
* El lanzador comprueba automáticamente tus archivos y descarga las actualizaciones.
* ¡Haz clic en **▶️ JUGAR** para comenzar la aventura!

<figure><img src="../.gitbook/assets/image_4.png" alt=""><figcaption></figcaption></figure>

<figure><img src="../.gitbook/assets/image_5.png" alt=""><figcaption></figcaption></figure>

💡 *Una vez instalado, el lanzador gestiona todas las actualizaciones automáticamente.*
